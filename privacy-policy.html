Privacy Policy — CS Autonova

Last updated: 3 November 2026

CS Autonova is a private automation tool built and operated by Rohit Kumar Chandoliya (Cheakstar Private Limited) to manage his own YouTube channel, ByteShield. It is used only by its owner. This page explains what data the application accesses and how it is handled.

Data the application accesses

With the channel owner's permission, CS Autonova uses the YouTube API Services to:

  • upload videos to the owner's own YouTube channel;
  • read and manage comments on the owner's own channel;
  • read channel analytics (such as views and watch time) for the owner's own channel.

The application does not access data from any other person's account, and it does not collect personal information about viewers.

How the data is used

The data is used only to operate the owner's channel: publishing videos, handling comments, and reviewing channel performance. Access tokens are stored locally on the owner's own computer. Data is never sold, never shared with third parties, and never used for advertising.

Data retention and deletion

Access can be revoked at any time by the owner from the Google account's security settings (Third-party access), which immediately stops the application from using the data. Locally stored tokens can be deleted by the owner at any time.
