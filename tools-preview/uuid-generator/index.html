UUID Generator

Generate unique IDs — one, or a whole list at once.

A UUID (Universally Unique Identifier) is a 128-bit label like 3f6a1c2e-9b4d-4a7f-8c1e-5d2a6b9e0f31 — used as database keys, file names and request IDs because two of them practically never collide. Version 4 is fully random; version 7 starts with the current time, so IDs sort in the order they were made.

Privacy: UUIDs are generated in this browser tab with the Web Crypto API (crypto.randomUUID() for version 4 and crypto.getRandomValues() for version 7) and never leave your device. Nothing is stored or sent anywhere.
