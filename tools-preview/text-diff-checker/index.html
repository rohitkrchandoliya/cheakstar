Text Diff Checker

Compare two texts line by line: what was added, removed or kept.

Lines only in the first text are shown as removed, lines only in the second as added, and matching lines as unchanged.

Privacy: both texts are compared only in this browser tab and are never sent to any server. The comparison is line-based, so a small edit inside a line shows the whole line as removed plus added.
