DNS Lookup

Find the DNS records (A, AAAA, MX, TXT, NS, CNAME, SOA) of any domain.

Look up a domain's DNS records using Google Public DNS (Cloudflare DNS as a fallback). This shows the public records anyone can see — useful for checking a website or email setup.

Privacy note: the lookup sends the domain name to Google Public DNS (dns.google), or to Cloudflare DNS if Google does not answer. Nothing is sent to Cheakstar.
