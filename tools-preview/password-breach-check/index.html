Leaked Password Check

Check a password against real breach data — without sending the password anywhere.

Only the first 5 characters of its scrambled fingerprint (SHA-1 hash) are sent to the Have I Been Pwned service; the match is completed on this device. This is called k-anonymity, and it is the safe standard way to do this check.

Safety: the password itself never leaves this page, and the box is cleared as soon as the check runs. Even so, do not type a password you currently use on an important account into any website as a habit — use this to test old or candidate passwords. Cheakstar receives nothing.
