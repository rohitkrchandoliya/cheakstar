CSS Gradient Generator

Build CSS gradients visually — linear, radial, corner and freeform mesh — copy the code, or export a PNG at any size.

Design a CSS gradient without guessing at the syntax. Pick a linear, radial, corner or freeform (mesh) gradient, set two to five colour stops, choose how colours blend, and the preview and the ready-to-paste CSS update as you work. You can also export the gradient as a PNG image at a custom size.

Freeform mode places each stop as a soft colour point — the first stops sit at the corners, a fifth at the centre — layered over the last stop as the base colour. It is a layered-gradient take on a mesh gradient, the closest plain CSS can get.

Export as a PNG image

PNG export is drawn with the browser canvas, which blends colours in sRGB and draws radial gradients as circles, so a PNG can look slightly different from the CSS preview when you pick another interpolation mode. The noise is a light random dither added per pixel to break up banding steps.

Good to know: stops are spaced evenly from 0% to 100% — if you need uneven spacing or a specific radial size and position, adjust the percentages in the copied CSS by hand. A browser canvas cannot blend in OKLCH or HSL, so PNG exports are rendered in sRGB; the interpolation choice applies to the CSS. The freeform (mesh) style is built from layered radial gradients, the closest plain CSS gets to a true mesh gradient. Everything is worked out in your browser; nothing you pick is sent anywhere, and no colour or setting is stored.
