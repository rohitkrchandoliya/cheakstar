CSS Gradient Generator

Build CSS gradients visually and copy the code.

Design a CSS gradient without guessing at the syntax. Pick a linear or radial gradient, set two to five colour stops, and the preview and the ready-to-paste CSS update as you work.

Good to know: stops are spaced evenly from 0% to 100% — if you need uneven spacing or a specific radial size and position, adjust the percentages in the copied CSS by hand. Everything is worked out in your browser with plain colour maths; nothing you pick is sent anywhere, and no colour or setting is stored.
