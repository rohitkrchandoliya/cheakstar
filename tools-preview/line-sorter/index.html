Line Sorter

Sort lines alphabetically, by length, numerically, or shuffle them.

Put any list into order — names for a register, items for a menu, roll numbers, words for a worksheet. Numbers inside lines are read as numbers, so "Item 2" correctly comes before "Item 10".

Privacy: your list is sorted only in this browser tab and is never sent to any server.
