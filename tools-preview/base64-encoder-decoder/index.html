Base64 Encoder & Decoder

Encode or decode Base64, for text and for files.

Text

Encode plain text to Base64, or decode Base64 back to text. Full Unicode is supported, so Hindi and emoji text work too.

File

Turn a small file (up to about 2 MB) into a Base64 string, or save a Base64 string back as a file — handy for data URIs and testing.

Privacy: everything runs in this browser tab. No text or file is sent to any server.
