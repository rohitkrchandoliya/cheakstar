CSV / JSON Converter

Convert CSV to JSON and JSON back to CSV, with a preview.

Convert data between CSV (spreadsheet style) and JSON (developer style), in both directions.

How CSV to JSON works: the first row is treated as the header, and every following row becomes one JSON object. All values stay text, exactly as written in the CSV. For JSON to CSV, paste an array of objects (or an array of arrays); the columns are the keys found across all objects. Your data never leaves this browser tab.
