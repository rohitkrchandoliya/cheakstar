Metadata Stripper

See exactly what an image or PDF says about you — camera, software, dates, even GPS — then download a clean copy with all of it removed.

Photos and PDFs quietly carry metadata: the camera or phone model, when a picture was taken, the software that made the file, and sometimes the GPS location where it was taken. This tool first shows you what it finds, then strips it by rebuilding the file. Your file is processed on this device only — it never leaves this browser tab.

About colour profiles: images are cleaned by re-encoding the pixels through the browser canvas. That removes EXIF, GPS, XMP, text chunks and the ICC colour profile — a browser canvas cannot re-attach a profile, so this tool honestly offers no “keep ICC” switch rather than pretending. Colours may shift very slightly on wide-gamut photos. PDFs are cleaned with the pdf-lib library (the same one our other PDF tools use): title, author, subject, keywords and creator are deleted; the library writes its own producer line and a fresh modification date when it saves, and that is stated openly here instead of being hidden.

Choose or drop a file to inspect its metadata.

Good to know: the readout shows only what this tool actually parsed — for JPEGs that is the EXIF block (camera make and model, software, capture dates, GPS presence and coordinates when stored), JFIF, XMP and ICC presence, and comment segments; for PNGs the text chunks, embedded EXIF, ICC profile name and timestamp chunk; for WebPs the EXIF, XMP and ICC chunks. A field that is not listed was not found, which is not a guarantee that no other hiding place exists — but re-encoding an image through the canvas rebuilds the pixel file from scratch, so nothing embedded survives into the download. Everything runs in this browser tab; nothing is sent anywhere.
