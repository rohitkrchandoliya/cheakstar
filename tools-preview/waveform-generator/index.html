Choose or drop an audio file to draw its waveform.

Good to know — please read: the waveform is drawn from the loudest channel peaks in each column, which is how waveform pictures are normally made — quiet detail inside a loud column is not shown. The preview sits on a chequerboard so a transparent background is visible; the chequerboard is never in the download. The SVG is true vector shapes (one rectangle per bar), so it scales cleanly but can get large on very detailed settings. Nothing is uploaded.
