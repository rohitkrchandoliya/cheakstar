SVG Optimiser

Shrink an SVG by removing editor junk, comments and needless precision — a safe, conservative optimiser that re-checks its own output before offering it to you.

Paste SVG markup or drop an SVG file. The optimiser removes what editors leave behind (comments, Inkscape/Illustrator metadata and namespaces, empty groups), rounds long decimal numbers to the precision you choose, and collapses whitespace. It never touches shapes, colours or referenced ids — and it re-parses the result to prove the SVG still works before showing it. Everything runs on this device only; your file never leaves this browser tab.

Paste or drop an SVG, then press Optimise.

Good to know: this is deliberately a safe, basic optimiser. It removes comments, editor metadata and namespaces, provably unreferenced ids, empty groups/definitions, excess whitespace and excess decimal precision. It does not merge paths, convert shapes, simplify curves or minify colours — the heavy rewriting a tool like SVGO does — because those can change how a file renders. The optimised output is re-parsed and rendered side by side with the original so you can see it still works. Everything runs in this browser tab; nothing is sent anywhere.
