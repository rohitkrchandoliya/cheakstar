Image Splitter

Cut an image into a grid of equal tiles — for Instagram carousels, puzzle posts and print layouts — and download them one by one or all together as a ZIP.

Choose how many columns and rows you want. Tiles are cut at the largest equal size that fits; if the image does not divide exactly, the leftover strip is shown honestly in the report instead of being silently stretched. Your image is processed on this device only and never leaves this browser tab.

Choose or drop an image to split it.

Good to know: tiles are named by position — tile-r1c1.png is row 1, column 1 — so they sort back into order in any file manager. Tiles are PNG, cut from the original pixels with no re-scaling. The ZIP is packed in your browser with the JSZip library (version 3.10.1, loaded from the jsDelivr CDN — the same CDN the site already uses); if that library cannot load, the individual tile downloads below still work. Everything runs in this browser tab; nothing is sent anywhere.
