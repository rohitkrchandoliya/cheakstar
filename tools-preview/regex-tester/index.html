Regex Tester

Test a regular expression live — matches highlighted, groups listed.

Type a pattern and some test text. Every match is highlighted in the text below, and each match's captured groups are listed — handy when building a pattern for emails, phone numbers or log lines.

Flags:

Quick reference

.Any character except a newline
\d \w \sDigit, word character, whitespace
\D \W \SNot a digit, not a word character, not whitespace
* + ?Zero or more, one or more, zero or one
[abc] [^abc] [a-z]A character set, a negated set, a range
(…) (?:…) (?<name>…)Capturing group, non-capturing group, named group
{n} {n,} {n,m}Exactly n, at least n, between n and m times
^ $ \bStart, end, word boundary
|Or — a or b
Good to know: this tester runs your pattern in the browser with JavaScript's own regular-expression engine — the same engine a web page would use. A very complex pattern on long text can freeze the page, because the browser runs the test on its main thread; keep test text short while building a pattern, and if a test hangs, reload the page. Patterns with nested repeats such as (a+)+$ are the classic slow case. Your pattern and test text never leave this browser tab.
