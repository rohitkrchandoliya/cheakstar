Website Security Headers Check

Grade a website's security headers with the free MDN Observatory service.

Grade a website's security headers with the MDN Observatory (Mozilla's current service). These headers are instructions a site sends your browser to protect you — against script injection, clickjacking, insecure connections and more.

Full report on MDN Observatory

Notes: the check runs on Mozilla's MDN Observatory service (the old observatory.mozilla.org API was retired in October 2024; this tool uses the current v2 API). One scan per minute per website is allowed, and a recent result may be shown from the service's cache — that is normal. The scan looks at the public homepage only. Nothing is sent to Cheakstar.
