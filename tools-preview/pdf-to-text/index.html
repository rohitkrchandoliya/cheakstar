PDF to Text

Pull the text out of a PDF and download it as a .txt file.

Pull the readable text out of a PDF. Preview it here, then download it as a plain .txt file.

Honest note: this reads the text stored inside the PDF. Scanned PDFs are pictures of pages — they contain no stored text, so extraction will come back empty for them (that needs OCR, which this free tool does not do). Everything runs in your browser using PDF.js by Mozilla; nothing is uploaded.
