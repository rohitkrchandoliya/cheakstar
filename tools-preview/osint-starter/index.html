OSINT Starter Tools

Look up DNS records, domain registration details, and IP address information using free public services. Everything runs in your browser. No account or sign-in is needed.

How these tools work. Your lookups are answered by free public services: Google and Cloudflare for DNS, the public RDAP directory for domain registration, and ipwho.is for IP information. The domain or IP address you type is sent to that service so it can answer your query. Nothing is stored by this page, and no sign-in is needed.

1. DNS Lookup

Find the DNS records of any domain: A, AAAA, MX, TXT, NS, CNAME, or SOA. Answered by Google DNS-over-HTTPS, with Cloudflare as a fallback if Google does not respond.

2. Domain Info (WHOIS / RDAP)

See who registered a domain, when it was created and when it expires, its nameservers, and its status. Answered by the public RDAP directory (the official successor to WHOIS).

3. IP Address Lookup

Find the country, city, ISP, network (ASN), and timezone of any IPv4 or IPv6 address. Answered by the free ipwho.is service (no key needed).

Source: ipwho.is (free tier). Location is approximate and comes from the IP address registry, not from GPS.

4. What's My IP

See your own public IP address, location, and internet provider, as the internet sees you.

Free-service limits: ipwho.is allows a shared number of free lookups per day for this website, so very heavy use may be refused for a while. If a lookup service is down, the tool shows a plain error message instead of a blank page.
