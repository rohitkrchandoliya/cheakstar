Palette Collection

Curated palettes, grouped by mood. Pick one and it loads above with names and CSS variables, ready to copy — the same way a palette library hands a set over to the generator.

Good to know: each colour name is the nearest of the 148 standard CSS colour names, matched by a weighted (redmean) distance — a close neighbour, not an official name for the exact colour. The category gently pulls every colour of the palette into that family (warm, cool, earth and so on). Harmonies are worked out from the colour wheel — complementary pairs sit opposite each other, analogous colours sit side by side, and triadic colours sit 120 degrees apart. A pretty palette is not a guarantee of readable text: always check that text on a colour has enough contrast before using it for headings or buttons. Everything runs in this browser tab; nothing is sent anywhere.
