Breach Checks

Find out whether an email address has appeared in known data breaches, and whether a password has been exposed in a breach. Both checks use free public services. Everything runs in your browser. No account or sign-in is needed.

Your privacy. The email address you type is sent to the free XposedOrNot service so it can check its breach database. Your password is never sent anywhere and never stored: only the first 5 characters of its SHA-1 hash leave your browser, and the password itself, and the full hash, never do. Nothing you type is stored by this page.

1. Email Breach Check

Check whether an email address has appeared in known data breaches. Answered by the free XposedOrNot API. A result of zero known breaches does not mean the address is safe — it only means it was not found in this database.

    Source: XposedOrNot (free tier, about 100 checks per day per visitor). This database is smaller than some paid ones, so a clean result here is not a guarantee.

    2. Leaked Password Check

    Check a password against a database of passwords exposed in real data breaches — without sending the password anywhere. Only the first 5 characters of its SHA-1 hash are sent to the free Have I Been Pwned Pwned Passwords service (k-anonymity), so the service cannot see your password. This is a real breach-database lookup, not a strength meter: a password can be strong-looking and still be leaked.

    Source: Have I Been Pwned Pwned Passwords (free, no key). Only the first 5 characters of the SHA-1 hash of your password were sent; your password and its full hash never left this device. A count of zero means the password was not found in this database — it does not prove the password is safe. Use a long, unique password for every account.

    If a check service is down or its daily limit is reached, the tool shows a plain error message instead of a blank page. If a password has been exposed, change it everywhere you use it and turn on two-factor authentication where it is offered.
