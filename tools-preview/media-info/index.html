Media Info

See a media file's duration, resolution, codecs, bitrate, every stream inside it — and how loud it is.

Honest limits, so there are no surprises: the media engine (ffmpeg) runs inside your browser and loads once (about 20–31 MB from a public CDN, then it is cached). Files up to about 50 MB work best; files over 100 MB are refused because browser memory is limited. The engine is a single-thread build, so reading and converting is slower than a desktop app. Your files are never uploaded anywhere.

Pick any audio or video file to see what is inside it: duration, resolution, codecs, frame rate, bitrates, audio channels, a stream-by-stream breakdown with the file's stored metadata, and a loudness panel (peak, RMS and an integrated LUFS estimate) measured by decoding the audio in your browser. Nothing is converted — the file is only read.

Loudness

Loudness is measured in your browser from the decoded audio with BS.1770-style K-weighting. The LUFS figure is an estimate — a certified loudness meter may differ slightly. Files whose audio this browser cannot decode (some codecs in video containers) show no loudness figures.
