Code Formatter & Minifier

Beautify JavaScript, HTML or CSS — or shrink JavaScript for shipping.

Paste code and make it readable again, or minify JavaScript to a compact form. Formatting uses the js-beautify parser and JavaScript minifying uses Terser — both run in this browser tab. Your code never leaves this device.

Good to know: formatting never changes what the code does — it only fixes spacing and line breaks. JavaScript minifying with Terser removes comments and whitespace and shortens local names where safe; HTML and CSS minifying here is a simple whitespace minifier, not a full parser, so check the result before shipping it. This page never runs your code (no eval() anywhere) — it only reads the text. Your code is processed in this browser tab and is never sent to any server. If the formatter libraries cannot load, the page says so instead of pretending to work.
