Internet Speed Test

Estimate your download speed by timing real downloads.

This test downloads fixed-size files from Cloudflare's public speed endpoint and times them, then works out the speed in megabits per second. It measures your download speed only — it does not test upload speed, because there is no server here to receive an upload.

Press Start speed test. The test downloads about 36 MB in total and takes a few seconds.

Good to know: the number is an estimate, not a certified measurement. It depends on your connection, the Cloudflare server you reach, Wi-Fi signal, and other devices using the same connection at the same time — run it again a minute later and the number can move. A single run is only a rough guide; the average of three runs is steadier. Upload speed is not measured and is never claimed. No account, no sign-up, and nothing about you is sent anywhere — the test only downloads public test data.
