Favicon Generator

Turn an image into a favicon set: an ICO file plus PNG icons in common sizes.

The set includes a classic favicon.ico plus PNG icons in the sizes browsers, phones and bookmarks ask for.

In your website's HTML head, the usual lines are: <link rel="icon" href="/favicon.ico" sizes="any"> and <link rel="apple-touch-icon" href="/favicon-180.png">. Put the files in the site's root folder.

Privacy: your image is processed only in this browser tab and is never uploaded. Non-square images are centred on a square canvas, so nothing is stretched.
