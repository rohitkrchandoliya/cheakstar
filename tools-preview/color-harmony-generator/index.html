Color Harmony Generator

Build colour harmonies from one base colour, fine-tuned with perceptual OKLCH sliders.

Choose a base colour and a harmony type — each type is explained in plain English. Then shape the whole set at once with the Lightness, Chroma and Hue sliders, which work in OKLCH so changes look even to the eye.

Good to know: harmonies are hue rotations in OKLCH space. The Lightness and Chroma sliders set absolute OKLCH values for the whole set (for Monochromatic, Lightness sets the middle step and the others step around it), and Hue shift rotates every colour together. If a colour would fall outside the sRGB gamut, its chroma is reduced just enough to fit, so every HEX here is displayable. Everything runs in this browser tab; nothing is sent anywhere.
