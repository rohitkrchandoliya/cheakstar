Audio Trimmer

Cut the exact part of a sound file you need — drag on the waveform or type the times, add fades, and export a clean WAV.

Drop an audio file, drag the gold selection on the waveform (drag the edges to fine-tune, drag the middle to move it), set optional fade in / fade out, and export. Everything is decoded and trimmed on this device only — your file never leaves this browser tab.

Choose or drop an audio file to trim it.

Good to know — please read: export is WAV only (uncompressed PCM). WAV files are large but lossless and open everywhere; this tool does not offer MP3 because a good MP3 encoder is a big extra library and re-encoding to MP3 would also lose quality. Fades longer than the selection are shortened to fit, and the status line tells you when that happens. Very long files are decoded fully into memory by your browser, so an hour-long file needs a fair amount of free RAM. Nothing is uploaded — the trim happens entirely in this tab.
