Choose or drop an audio file to measure its loudness.

Good to know — please read: the loudness figure is an approximation: it uses the ITU-R BS.1770 K-weighting filters and the standard two-stage gating, computed on your file in this browser, but it is not a certified broadcast meter — treat the last decimal as indicative, and expect very short clips (under a second) and near-silent material to measure unreliably. Channels are all weighted equally (a dedicated LFE channel, if any, is not excluded). Export is WAV (uncompressed, lossless), and normalising only changes overall gain — it does not compress dynamics, so a very dynamic recording may still sound uneven. If the clip guard caps the gain, the file honestly ends up below target rather than distorted. Nothing is uploaded.
