JWT Decoder

Read a JSON Web Token's header and payload — on your device only.

Paste a JWT (three base64url parts separated by dots) to see its header and payload as readable JSON, with the expiry status worked out from the exp claim. Decoding is not verification: this page only reads the token — it never checks the signature, so a decoded token may still be forged or expired.

Privacy — read this first: your token never leaves this device. Decoding happens only in this browser tab, and this page makes no network request at all — there is no server to send your token to. Even so, treat a real token like a password: do not paste a live production token into any website, including this one, unless you are sure it is safe to expose. Decoding a token does not verify it — anyone can forge the contents of an unsigned or wrongly signed token.
