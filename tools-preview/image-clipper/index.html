Image Clipper

Trim the transparent edges off a PNG or WebP — down to the smallest box that still holds every visible pixel, with an exact report of what was cut.

Logos, icons and stickers often carry a wide transparent margin. This tool scans the alpha channel, finds the tightest box around the actual content and cuts the rest away. Your file is processed on this device only — it never leaves this browser tab.

Change it after loading and the report updates instantly.

Choose or drop an image to clip it.

Good to know: a pixel counts as content when its alpha value is above 0 — even a faint, almost invisible shadow pixel keeps its row and column alive. The output is always a PNG, because PNG keeps the transparency exactly; a WebP input is therefore converted to PNG. If the image turns out to be fully opaque there is nothing to trim, and the download then gives you your original file back, byte for byte unchanged. Everything runs in this browser tab; nothing is sent anywhere.
