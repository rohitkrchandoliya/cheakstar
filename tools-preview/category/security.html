Security & OSINT

Ten checkers that look at public information and explain what it means. Find a domain's DNS records and registration details, see which country, city and provider an IP address belongs to, check your own public IP, list a domain's subdomains from public certificate logs, and grade a website's security headers. You can also check whether an email address has appeared in known data breaches, test a password against breach data in a way that never sends the password itself, see the GPS and camera details hidden inside a photo, and check a phone number's country and line type. The lookup tools send the value you type to public databases; each tool's own page carries a note about what it sends. Written for website owners, students learning security, and anyone checking a detail that looks suspicious. Two password tools join the set: a generator that creates strong random passwords on your device, and a strength checker that rates a password privately, without sending it anywhere.
