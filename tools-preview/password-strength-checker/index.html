Password Strength Checker

Check how strong a password really is, privately on your device.

Length alone does not make a password strong — a long one built from a common word, a name or a keyboard pattern can still fall quickly. This checker uses the zxcvbn library, which estimates strength the way an attacker would meet it: dictionary words, patterns, repeats and dates all count against it.

Type a password, then check it — the check runs here in your browser as you type.

Good to know: the password you type is never transmitted, stored or logged — the zxcvbn library runs entirely in your browser on this device, and the field is cleared from the page when you close or reload it. This tool checks strength only: how hard the password is to guess. It does not check whether the password has appeared in a data breach, and a strong score is not a promise — a password reused on a site that leaks it is weak everywhere it is reused. Use a different strong password for every account, kept in a password manager.
