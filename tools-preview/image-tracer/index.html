Image Tracer

Turn a raster image — a logo, drawing or icon — into a clean, scalable SVG vector, traced entirely in your browser.

Drop an image, pick a preset, and trace. Fewer colours and a higher minimum path size give a simpler, bolder result; more colours keep photo detail at the cost of a bigger file. For speed the image is traced at up to 800 px on its longest side — the Scale control sets the SVG's output size. Your image is processed on this device only and never leaves this browser tab.

Choose or drop an image to trace it.

Good to know: tracing is done by the open-source ImageTracerJS library (version 1.2.6, public domain / The Unlicense, by András Jankovics), loaded from the jsDelivr CDN; if it cannot load, this page says so plainly instead of faking a result. Flat logos and icons trace best. Photographs trace honestly but with many paths — the Photo preset keeps up to 48 colours, and the file can grow large; that is the real trade-off of vectorising a photo, not a fault. Everything runs in this browser tab; nothing is sent anywhere.
