Good to know: the name is the nearest of the 148 standard CSS colour names, matched by a weighted (redmean) distance in sRGB, so it is a close neighbour, not an official name for your exact colour. OKLCH and Lab are worked out through linear sRGB with the standard CIE D65 reference white. The alpha slider only affects the HEX + alpha and RGBA rows; the other formats describe the solid colour. Everything runs in this browser tab; nothing is sent anywhere.
