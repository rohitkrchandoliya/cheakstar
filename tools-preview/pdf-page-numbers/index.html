PDF Page Numbers

Add page numbers to a PDF, on your device.

Choose a PDF and this tool writes a page number on every page — as "Page 3 of 12", "3 of 12", or a plain "3" — in the corner or centre you pick. Numbering can start from any number, which helps when the PDF is one part of a larger document.

Download numbered PDF
Good to know: your PDF is processed on your device only, using the open-source pdf-lib library (MIT licence) — the file is never uploaded or sent anywhere. The numbers are drawn onto a new copy; your original file is not changed. The "of Y" total is the page count of this PDF, even when numbering starts from a different number. Password-protected or damaged PDFs cannot be numbered, and the tool will say so plainly.
