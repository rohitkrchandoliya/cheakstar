Image Compressor

Shrink a JPG, PNG or WebP image to a smaller file size.

Two ways to shrink: set a quality level, or set a target size in KB and let the tool find the best fit — for example when a form upload limit refuses your photo.

Lower quality means a smaller file but a softer image. PNG output ignores the quality setting (PNG is lossless), so pick JPEG or WebP for the smallest files. Target-size mode tries several quality levels and keeps the best fit; very small targets may not be reachable without shrinking the image, and the page will say so.

Privacy: your image is processed only in this browser tab and is never sent to any server.
