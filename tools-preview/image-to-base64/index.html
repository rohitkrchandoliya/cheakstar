Image to Base64

Convert an image to a Base64 string, and back, on your device.

Developers and website builders often need an image as text — for example to embed a small icon directly inside HTML or CSS. The first part below turns an image file into its Base64 data URL; the second part does the reverse, turning a pasted Base64 string or data URL back into a viewable, downloadable image.

Image to Base64

Base64 back to image

Good to know: files never leave your device — the conversion happens in this browser tab and nothing is uploaded anywhere. Base64 makes data about one third larger than the original file, so it suits small images like icons and logos; large photos are better kept as normal files. When you paste plain Base64 without a data URL header, the tool assumes a PNG image — if the preview does not appear, paste the full data URL (starting with data:image/...) instead.
