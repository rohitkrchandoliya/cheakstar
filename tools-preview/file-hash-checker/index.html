File Hash Checker

Get the SHA-256 and MD5 hash of any file, for verifying downloads.

A hash is a file's fingerprint: if even one byte changes, the fingerprint changes completely. Download sites publish SHA-256 values so you can prove the file you received is the file they sent. Pick a file to get its SHA-256 and MD5 fingerprints.
