Video Compressor

Make a video file smaller: 720p or 480p at your chosen quality.

Honest limits, so there are no surprises: the media engine (ffmpeg) runs inside your browser and loads once (about 20–31 MB from a public CDN, then it is cached). Files up to about 50 MB work best; files over 100 MB are refused because browser memory is limited. The engine is a single-thread build, so compressing is slower than a desktop app. Your files are never uploaded anywhere.
