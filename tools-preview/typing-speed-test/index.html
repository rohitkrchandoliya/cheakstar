Typing Speed Test

A one-minute typing test with words per minute, accuracy and error highlighting.

Type the passage below exactly as shown. The clock starts with your first keystroke and runs for 60 seconds. Your speed is counted in words per minute (WPM), where one word means five characters, and every wrong character is shown in red as you type.

60 seconds left  ·  0 WPM  ·  100% accuracy

Press Start test, then type the passage. A fresh passage is given each time.

Good to know: WPM here follows the standard typing-test rule — one "word" is five characters, so it counts correctly typed characters divided by five, divided by the minutes spent. Accuracy is the share of typed characters that match the passage. Passages are written for this site, and nothing you type is sent anywhere or stored — the test runs entirely in this browser tab.
